# docs/speculative/

Design memos, investigation notes, and proposals that are NOT yet
tied to a shipped RC. Things in this folder are exploratory; promote
to `docs/v<version>-<feature>-readme.md` (top-level docs/) when a
proposal becomes a shipped RC.

Typical contents:
- "what would we need to do to X" memos
- bottleneck investigations that haven't produced a fix yet
- design alternatives being compared
- deferred-list elaborations

Anything moved out of here should be referenced/replaced by a stub
("promoted to vX.Y.Z-foo, see docs/vX.Y.Z-foo-readme.md") so the
provenance trail stays clear.
