# v0.24.103 — post-FX 1c: move the tonemap into present.frag (true HDR scene)

Gated behind `UNENDLICH_POSTFX`. The ACES tonemap + v0.24.91 cinematic grade +
vignette move out of `chunk.frag` into the shared `tonemap.glsl`, and under
post-FX they run ONCE in `present.frag` at the end. The offscreen scene buffer
now holds **linear HDR scene color above 1.0** instead of a tonemapped [0,1]
image — which is what bloom and an HDR-correct SSR composite need. Still
identical-looking by design.

## What changed (all POSTFX-gated)
- New `shaders/tonemap.glsl`: `aces_film`, `filmic_contrast`, `tonemap_grade`
  (the grade knobs), `apply_vignette(color, screen_uv)` — moved **verbatim**
  from chunk.frag's old tail, so the math is unchanged.
- `chunk.frag`: includes `tonemap.glsl` (its local `aces_film`/`filmic_contrast`
  are gone, now shared). The tonemap tail is guarded: when `ubo.wind_params.w <
  0.5` (post-FX off) it tonemaps + vignettes exactly as before; when post-FX is
  on it skips, writing linear HDR into the offscreen target.
- `present.frag`: no longer a passthrough — it samples the linear HDR scene,
  applies the same `tonemap_grade` + `apply_vignette` (using its fullscreen
  `v_uv`), and writes the swapchain. It only ever runs under post-FX, so it
  always tonemaps. This is the composite stage bloom/SSR will add into, in
  linear, BEFORE the tonemap.
- `world_renderer.rs`: sets `wind_params.w = 1.0` when post-FX is active, else
  `0.0` (the flag chunk.frag reads). `wind_params.w` was previously unused and
  no other shader reads it, so no UBO layout change.

## Why identical
- POSTFX off: chunk.frag runs the verbatim-moved chain → byte-identical.
- POSTFX on: chunk.frag writes linear scene radiance to RGBA16F (no clamp);
  present.frag runs the same `tonemap_grade(linear)` + vignette. ACES handles
  values > 1.0 identically whether tonemapped in-shader or in present, the float
  buffer preserves the linear value, and the vignette is radial from screen
  centre in both (`gl_FragCoord/viewport` vs `v_uv`, both [0,1]).
- There is a single `out_color` write and a single tonemap site in chunk.frag;
  the underwater path just modifies `color` and falls through, so it's covered
  by the same guard.

## Acceptance / A/B
`POSTFX=1` must look identical to `POSTFX=0`. The failure modes to watch, all
isolated to the post-FX path: a washed-out / double-bright scene (double
tonemap — flag stuck off), a flat un-graded scene (no tonemap — flag stuck on),
or a vignette that doesn't match. Flip `UNENDLICH_POSTFX` to compare. Grade
knobs now live in `tonemap.glsl`.
