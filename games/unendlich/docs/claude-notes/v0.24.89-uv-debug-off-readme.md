# v0.24.89 — "white blocks" (UV-debug checkerboard) off

**Brick:** `unendlich-v0.24.89-uv-debug-off.zip` (patch series, `git am --3way`)
**Files:** 1 (`shaders/chunk.frag`)
**Stacks on:** v0.24.88 (independent — different file).
**Status:** one-line shader change; not compiled here (no glslang in sandbox).
The `.spv` is regenerated by `build.rs` on your `cargo build`.

---

## What this is

The grey "white blocks" / checkerboard on every surface was **not** a missing
texture, a missing color, or a mesher bug. It's a leftover **debug overlay** in
`chunk.frag`:

```glsl
const bool SHOW_UV_DEBUG = true;   // <- was on
```

That block multiplies every fragment by a 2×2 checker plus grid lines
(`color *= mix(0.78, 1.0, checker)` and a border darken) to prove per-face UVs
reconstruct correctly — a texturing-increment-1 diagnostic. Its own comment says
"Set SHOW_UV_DEBUG to false to return to normal rendering," and it never got
turned back off.

Because it lives in the **render** path (`chunk.frag`), it sits on top of every
mesher mode (CPU / sparse / octree), which is why the magenta and winding bricks
— both mesher-side — never touched it.

## The change

Flip it off:

```glsl
const bool SHOW_UV_DEBUG = false;
```

Blocks now render at their solid lit colors (stone grey, grass green, etc.). The
subtle beveled-edge + grain in the "per-face procedural detail" block earlier in
the shader is left on — that's the gentle block-edge definition, not the
checker. Flip `SHOW_UV_DEBUG` back to true only to re-verify UV reconstruction.

## Apply

```bash
./toolkit/apply_from_zip_v2.sh unendlich-v0.24.89-uv-debug-off.zip /path/to/unendlich-game
```

Expect `WARNING: base … not present — applying anyway` (the base sha is my
snapshot's; yours differs). It changes only `chunk.frag`, so it applies cleanly
regardless of which prior bricks are in.

## Verify

`build.rs` recompiles `chunk.frag` → `chunk.frag.spv` on build:

```bash
cargo build --release -p unendlich-engine --features render
UNENDLICH_GPU_MESHER=2 cargo run --release --bin unendlich-world --features="render,gpu,window"
```

Surfaces should be flat solid colors with no checker and no grid lines.

## NOT in this brick: "no ceiling looking up"

Separate issue, deliberately not bundled. After this brick the face windings are
all verified correct (the v0.24.88 bumpy top was the only inverted one), so
downward/underside faces are **not** being culled — a genuine solid ceiling
above you would render. The likeliest explanations for seeing sky when you look
up are that the space is actually open there (ravine / cave-mouth / pit, or
open-topped procedural caves from the cave-gen work), and the scattered green is
tree canopies (leaves are solid blocks) seen from below.

Decisive test (see chat): pillar up a few stone blocks and roof yourself in, then
look up. If your placed roof's underside renders, the renderer is fine and the
open "cave" is world-gen; if it's invisible from below, that's a real underside
bug and gets its own brick.
