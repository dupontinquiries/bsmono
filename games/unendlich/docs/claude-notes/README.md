# docs/claude-notes/

Notes Claude has written during an autonomous session — RC ships,
investigations, prep work for future sessions, etc. Distinct from
`docs/` proper (which holds the canonical per-RC readmes following
the project's pre-existing convention) so that:

1. The user can scan their own-authored docs separately from
   Claude-authored ones.
2. Once a note here has been reviewed and accepted, it can be
   promoted to `docs/v<version>-<feature>-readme.md` to merge into
   the canonical history.
3. Speculative or in-flight investigations are not mixed into the
   stable docs trail until they've been vetted.

When in doubt about which file should live in `docs/` proper vs.
`docs/claude-notes/` vs. `docs/speculative/`: if a human (you) hasn't
reviewed it yet, it goes here.
