# v0.24.91 — cinematic color grade (exposure + vibrance + split-tone)

**Opt-in brick.** Apply with `toolkit/apply_from_zip_v2.sh`. **Shader-only**
(`chunk.frag`) — no `.spv`, no bindings, no host changes. Independent of the
winding/revert situation (that was `mesher.rs`/`meshing_pool.rs`; this touches a
different file and applies cleanly on top of any current tree).

## What this adds

`chunk.frag` already does ACES tonemapping, filmic contrast, and a proper
screen-space vignette — but it had **no exposure control and no color grading**.
This adds a final-stage grade with three tunable knobs:

| Const | Default | Neutral | Effect |
|-------|---------|---------|--------|
| `EXPOSURE`   | `1.0`  | `1.0`  | Scales scene radiance **before** the ACES curve, so raising it brightens midtones while highlights roll off gracefully instead of clipping to white. |
| `SATURATION` | `1.10` | `1.0`  | Vibrance — pulls color away from its luminance. Mild richness. |
| `SPLIT_TONE` | `0.35` | `0.0`  | Blend toward a luma-based warm/cool split (teal shadows / orange highlights — the classic cinematic separation). Kept subtle (±~8% tint at full strength). |

They're compile-time consts near the bottom of `main()` in the
"Tone mapping & color grading" block. With **hot-shaders** you can edit them and
rebuild to see the change live. Set each to its neutral value to disable that
term; the defaults are deliberately conservative.

It's pure final-stage math in the existing pass — no new render targets, no
descriptor changes, ~free on the GPU.

## Also

Corrects the stale `froxel_volume` header comment. It said "v0.16 groundwork /
volume is unfilled / falls back to the per-fragment march" — that's wrong: the
froxel volume is **live** (filled every frame by `froxel_fill.comp`, dispatched
from `world_renderer` before the color pass). That stale comment is what made
the volumetric fog look like it still needed wiring; it doesn't.

## How to tune

1. Apply the brick, build with `hot-shaders`.
2. Open `crates/unendlich-engine/src/shaders/chunk.frag`, find the three consts.
3. Bump `EXPOSURE` toward `1.1–1.3` if the scene reads dark; drop it if blown
   out. Push `SATURATION` to `1.2`+ for a more saturated look, or back to `1.0`.
   Raise `SPLIT_TONE` for a stronger filmic teal/orange, lower for neutral.
4. Rebuild; the grade updates without touching anything else.

## Scope / what's next

This is the safe in-shader portion of the "more camera effects" goal. The
bigger AAA-feel items — **bloom**, **ambient occlusion**, **screen-space
reflections** (for realistic water), and **anti-aliasing/TAA** — need new
render passes / targets (and real bloom wants an offscreen HDR target, since
tonemapping currently happens inside `chunk.frag`). Those are the next tier and
I'll build them carefully and grounded in the existing pass/blur infrastructure
(`ui_downsample.comp` / `ui_blur.comp` are reusable for bloom), not blind, since
a wiring mistake there is a black screen rather than a visual nitpick.

`chunk.frag` is otherwise already strong: fresnel + animated waves + depth tint
+ specular on water, wet-fresnel stone, hemisphere ambient, altitude + Rayleigh
sky tinting, HG-phase volumetric fog. So further uplift comes from the passes
above, not more per-fragment tweaks.
