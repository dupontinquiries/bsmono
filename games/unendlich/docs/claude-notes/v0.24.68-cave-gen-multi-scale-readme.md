## What this ship does

Replaces single-noise cave threshold (`noise > 0.78`, ~5% volume)
with a three-layer density model when env flag is set:

```rust
let worm    = noise_3d(x*0.05,  y*0.05,  z*0.05,  seed+CAVE);
let chamber = noise_3d(x*0.012, y*0.012, z*0.012, seed+CAVE_CHAMBER);
let depth   = ((20.0 - y) / 60.0).clamp(0.0, 1.0);
let seepage = noise_3d(x*0.15, y*0.15, z*0.15, seed+CAVE_SEEP) * depth;

let density = worm * 0.6 + chamber * 0.3 + seepage * 0.1;
density > self.cave_threshold  // default 0.6
```

The three layers contribute different morphologies:

- **WORM (60%, ω=0.05)** — same params as the original `is_cave`.
  The dominant tunnel network.
- **CHAMBER (30%, ω=0.012)** — coarser-frequency, sparser. Where
  it coincides with a worm tunnel, produces an open chamber.
- **SEEPAGE (10%, ω=0.15, depth-scaled)** — fine-frequency veins
  that only appear well below the surface (linear ramp y=20 → y=-40).

## Activation

```bash
# Default behavior preserved (single-noise):
cargo run --release --bin unendlich-world ...

# Multi-scale caves at default threshold (~8-15% volume):
UNENDLICH_MULTI_SCALE_CAVES=1 \
  cargo run --release --bin unendlich-world ...

# Tune threshold (lower → more caves):
UNENDLICH_MULTI_SCALE_CAVES=1 UNENDLICH_CAVE_THRESHOLD=0.55 \
  cargo run --release --bin unendlich-world ...
```

Init log on activation: none currently — `is_cave` is hot-path
and the flag is read once at construction. Consider adding a
log line in `WorldModel::new` if A/B testing needs explicit
confirmation. (Not done in this RC to avoid changing other
test outputs.)

## Threshold tuning table (rough — actual depends on noise stats)

| Threshold | Volume | Feel |
|---|---|---|
| 0.50 | ~30-50% | dense Swiss cheese |
| 0.55 | ~15-30% | cavernous |
| **0.60** (default) | ~8-15% | moderately rich |
| 0.65 | ~3-8% | mild increase |
| 0.70 | ~1-3% | sparse |

Pre-RC33 single-noise model: ~5% volume.

## Architecture changes

### Two new seed constants

```rust
mod seeds {
    // ... existing constants ...
    pub const CAVE:         u32 = 0xCA0E_0000;  // (existing) worm tunnels
    pub const CAVE_CHAMBER: u32 = 0xCA0E_0001;  // (new) low-freq chambers
    pub const CAVE_SEEP:    u32 = 0xCA0E_0002;  // (new) high-freq seepage veins
}
```

### Two new fields on WorldModel

```rust
pub struct WorldModel {
    // ... existing fields ...
    multi_scale_caves: bool,  // env: UNENDLICH_MULTI_SCALE_CAVES
    cave_threshold: f64,      // env: UNENDLICH_CAVE_THRESHOLD (default 0.6)

```

Read from env once in `WorldModel::new`. Defaults preserve
existing behavior.

## Tests added

Three new tests in the existing `tests` mod:

1. **`cave_gen_default_preserves_single_noise_path`** —
   bedrock-band rule (y < 4 always solid) holds with default config.
2. **`cave_gen_multi_scale_deterministic`** — two
   `WorldModel::new(seed)` instances produce identical `is_cave`
   decisions across a swept volume. Branch-agnostic; works
   regardless of env state.
3. **`cave_gen_bedrock_band_always_solid`** — bedrock rule
   under both code paths across a wider x/z sweep.

Existing tests are unaffected — the default-off behavior keeps
their outputs byte-identical.

## Performance

- 3 noise lookups instead of 1 when flag is on.
- `is_cave` is ~5% of chunk-generation cost; full impact <2%
  slower gen.
- When flag is OFF: identical performance (early branch on
  bool).

## What this is NOT

Just Step 1 of the four-step plan. This is "noise statistically
shaped like erosion" — NOT actual erosion simulation. No moisture
field consumption, no drainage map, no surface erosion. Those
are deferred:

- **Step 2**: region-scale drainage map (~300 LoC). Caves bias
  toward high-flow paths. Introduces `world::drainage`.
- **Step 3**: `geological_moisture` field (~150 LoC). Karst-style
  cave coupling at long timescales.
- **Step 4**: heightmap erosion (500-1000 LoC). Modifies surface
  terrain via simulated water flow. Biggest payoff, biggest
  effort.

See `docs/speculative/cave-generation-and-erosion.md` for the
full plan and trade-offs.

## Risks

- **Stale saved worlds**: enabling the flag on a world saved
  with it off → cave morphology changes; existing edits in
  `explicit_indices` apply on top of the new baseline. Some
  edits may land mid-air or mid-stone. Acceptable since flag
  is opt-in.
- **Threshold tuning**: 0.6 is a guess for "more caves without
  flooding." Real noise statistics may vary the volume estimate
  ±50%. Tune via env if needed.
- **Performance**: 3× noise lookups in cave check; small
  fraction of total gen cost. <2% gen slowdown when on, zero
  when off.
