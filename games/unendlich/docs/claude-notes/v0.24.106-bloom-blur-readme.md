# v0.24.106 — bloom: separable blur (soft glow)

Second bloom increment. Adds the separable Gaussian blur on top of the
v0.24.104 bright-pass, turning the mild half-res bright-pass into an actual soft,
wide glow. Same gate (`UNENDLICH_BLOOM`, requires `UNENDLICH_POSTFX`).

## What changed

- New `shaders/bloom_blur.frag`: a 9-tap HDR separable Gaussian (the `ui_blur`
  kernel, but a fragment shader writing the RGBA16F bloom target instead of the
  rgba8 the UI blur clamps to). Push constant `vec2 dir_texel` = the per-tap
  step along the blur axis.
- `render/bloom.rs`:
  - second half-res ping-pong target (`scratch` = B; `target` = A is the result
    the present pass samples) + its framebuffer + a blur pipeline with two
    descriptor sets (one reading A, one reading B).
  - `record()` now does bright-pass (scene→A), then `BLOOM_BLUR_PASSES` × {H:
    A→B, V: B→A}. The blur reuses the SAME bloom render pass — its WAR/RAW
    external dependencies already make the A↔B ping-pong safe across passes and
    frames, so no new barriers.
- `present.frag` is unchanged: it still samples the bloom target (now blurred).

## Tunables (consts in `render/bloom.rs`)

- `BLOOM_BLUR_PASSES` — iterations of H+V. **0 = raw bright-pass (the v0.24.104
  look — a clean A/B fallback)**, 1 = soft glow (default), 2 widens it further.
- `BLOOM_INTENSITY` (0.05), `BLOOM_THRESHOLD` (1.0), `BLOOM_KNEE` (0.5) as before.

## A/B

1. `UNENDLICH_POSTFX=1` without `UNENDLICH_BLOOM` → identical to v0.24.103 (the
   composite is still a no-op when bloom is off).
2. `UNENDLICH_POSTFX=1 UNENDLICH_BLOOM=1` → bright areas now have a **soft,
   spread-out glow** rather than the blocky/half-res brightening of v0.24.104.
3. To isolate blur from bright-pass: set `BLOOM_BLUR_PASSES = 0` and rebuild →
   you get exactly the v0.24.104 bright-pass. `= 2` → wider, softer.

Note: this stacks on the v0.24.104 bright-pass, which you may not have run yet.
If bloom looks wrong, set `BLOOM_BLUR_PASSES = 0` first to check the bright-pass
alone, then `= 1` to add blur — that splits the two suspects.

## Validator

`70 ok, 0 warn, 0 error` (+3 for `bloom_blur.frag`: delimiters, 1 binding,
~8-byte push).
