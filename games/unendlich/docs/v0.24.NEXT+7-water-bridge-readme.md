# v0.24.NEXT+7 — water chunk↔field bridge (seed + ground heights)

## What

The connective tissue between a chunk's water blocks and the
`WaterField` foundation (v0.24.NEXT+6): the two pure functions the water
simulation will call to initialize and settle a field from worldgen.

- `WaterField::seed_from_chunk(chunk, fluid)` — per-column depth = count
  of `fluid` blocks in that column. `total_volume()` then equals the
  chunk's fluid block count by construction, so settling (volume-
  conserving) preserves the world's water mass.
- `ground_heights_from_chunk(chunk, fluid)` — per-column floor height
  (topmost non-air, non-fluid cell + 1) — the `ground` argument
  `settle_step` needs.

With these, the full **seed → settle** loop runs from a real chunk, and
is tested end-to-end.

## Why it's a bridge, not the visible feature

Real field-driven water (partial fills, flowing, smooth settled
surfaces) needs a *persistent, simulated* field — stored per chunk and
settled each tick. That integration is currently **blocked** on files
not in this crate slice:

- `Chunk` has no slot for field side-state (only `blocks` + index sets);
  adding one touches its procedural/explicit storage + serialization
  model — risky to do blind.
- `leaf_decay.rs` / the sim scheduler (the per-chunk tick-driver pattern
  water settling would follow) aren't present here.

So this ship deliberately stops at the **pure, tested bridge** — no
storage, no tick, no rendering. Mesh-time-derived fields were considered
and ruled out: without settling they reproduce the block heights exactly
(no visible change), and settling per-chunk-only would create cross-chunk
seams. The honest visible payoff waits for the persistent field. See
`docs/CLIMATE_PATH.md` for the remaining steps.

## Why it's safe

- **Pure + inert.** Nothing constructs a field yet; this is library code.
  Zero runtime/worldgen/render change — cannot affect a playtest.
- **Reads via `Chunk::get`** (public), so it lives in the `world` layer
  with no dependency on the render-side mesher.
- **Documented approximation.** Ground heights treat "not Air, not fluid"
  as solid (folds the other fluid + thin plants into ground) because
  `BlockId` solidity predicates aren't in scope. Accurate for lakes/
  oceans over terrain; the sim can swap in a real `is_solid` later.
