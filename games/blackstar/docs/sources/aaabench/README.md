# Source: aaabench (MIT licensed)

These two files are copied verbatim from
https://github.com/ukanwat/aaabench (README badge confirms MIT), a
benchmark repo for agentic coding models building open-world games in
Unreal Engine 5. They are GTA-scale open-world production knowledge —
not this project's own material, and not written for this project's
genre or fiction.

`ART_BIBLE.md` Section 5 ("THE HUMAN FOREGROUND") cites both of these
and explains what was adapted versus rejected — this project's Earth
is a besieged, post-invasion setting, not a functioning peacetime
city, and the vocabulary here (shopfronts, dealership rows, retail
signage) was translated to this fiction's own equivalents rather than
imported wholesale. Read ART_BIBLE.md Section 5 first; these are the
reference material behind it, kept here so the citation is checkable
without needing the original upload.

Not modified from the original — if aaabench updates these files, this
copy will drift, and that is fine; it is a snapshot, not a live link.
