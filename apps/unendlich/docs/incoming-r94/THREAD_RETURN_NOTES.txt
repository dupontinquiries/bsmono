Pure core: step(state: DhtState, input: Input, now: Time) -> (DhtState, Vec<Envelope>) — no std::net, no clock (time passed in), deterministic. Input{Start, Deliver(Envelope), Poll}, Msg{Ping,Pong,FindNode,Nodes,JoinRequest,JoinAck}, Phase{Idle,Finding,Joining,Joined,Failed}. Flow: Start→FindNode(self) to bootstraps; Nodes→learn peers, advance to Joining, emit JoinRequest to the closest; JoinAck→learn peers, Joined; existing nodes answer FindNode with Nodes (closest by XOR) and JoinRequest with JoinAck; Poll past the deadline retries up to MAX_RETRIES then fails. PeerTable is bounded (PEER_CAP=16), never self, dedup, evicts farthest by XOR distance; closest(target,k) is XOR-ordered. Consts TIMEOUT=2.0, CLOSEST_K=4.
Landing: DhtJoin service (peer table + machine + accumulated clock) registered into sim::service_registry via the exact co-located #[distributed_slice(SERVICES)] template from SHARED_RULES (name "dht_join"); its tick advances time and Polls — an idle no-bootstrap seed, so neutral ticks are panic-free.
