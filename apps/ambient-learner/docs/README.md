# This file is intentionally short.

The real documentation entry point is [`_INDEX.md`](_INDEX.md).

This file used to describe a "Qt/QML barebones scaffold" version
that is long obsolete — the project has since grown three full UI
backends (GTK, Qt/QML, Iced), real worker threads, a public IPC
service, ML temperature prediction, and a published screen-temp
bitfield. Keeping the old content here would actively mislead a
new reader, so it's been removed.

If you're trying to orient yourself in the codebase, start with:

- [`_INDEX.md`](_INDEX.md) — explains the curated docs set vs the
  historical pile in this directory
- [`00_CLAUDE_CONTEXT.md`](00_CLAUDE_CONTEXT.md) — the load-bearing
  "if you read one thing, read this" file for a fresh session
- [`01_OVERVIEW.md`](01_OVERVIEW.md) — what the project is and isn't
