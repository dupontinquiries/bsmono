# Performance Audit — idle/in-use cost (v0.1.749)

Generated by scripts/perf_audit.py (static QML timer + signal-fanout scan).
scripts/perf_regression.py locks the metrics so a future feature mix can't
silently reintroduce an idle drain. Run both anytime.

## Acted on v0.1.749
- Wake-word + ask-AI event polls (2x 250ms = 8Hz constant) now gate on
  backend.voice_wake_listening() — when no wake word is registered (the
  common case) they stop entirely instead of waking the backend forever.
  This is the user's flagged voice-path idle drain. 'Better even in use':
  the poll vanishes when the feature isn't set up, not just when backgrounded.

## Remaining levers (ranked)
- _pagerPoll (400ms, running:true) is the last always-on timer — could gate
  on pager-active state.
- on_term_output_changed fans out to 7 handlers; a burst of PTY output
  triggers all 7. Coalesce into one rAF-style repaint per frame.
- VAD energy gate on the voice capture chain so transcription only wakes on
  actual speech, not every poll tick (the user's batching point).
