# Capabilities

This page answers "what can I do" — and the long-term plan is for it to
be generated live from the app's current context, so it always reflects
exactly what's available where you're standing. For now it's the curated
overview; the dynamic version is tracked as a TODO.

## Right now you can

- **Browse the web by voice or type** — say a site or a search, or type
  a URL. Read articles aloud, paragraph by paragraph.
- **Run a terminal** — say or type shell commands. Editors and debuggers
  (helix, gdb) get their own voice command sets when they open.
- **Talk to a local model** — a private, on-device assistant. Say
  "chat" to open it.
- **Build a voice profile** — so the app recognizes you specifically.
  See [[Voice Setup]].
- **Move through the graph** — see [[Getting Around]] for the movement
  vocabulary.

## How to discover more

The app is built to announce itself rather than hide features:

- Say **"what can I do"** anywhere — the words that work in your current
  context surface automatically.
- When a debugger or editor opens, a prompt shows the voice commands for
  it.
- The man pages (like this one) are linked nodes on the graph — follow
  the lines to learn each area.
